# Project working agreement

- Read `docs/STATUS.md` and `docs/BACKLOG.md` before work.
- Update both documents after every milestone, feature, important decision, or blocker.
- Record material tradeoffs in `docs/DECISIONS.md` and actual validation in `docs/VALIDATION.md`.
- Never mark a runtime or CI result verified without executing it and recording evidence.
- Never commit credentials, private lab addresses, raw security reports, or local tool downloads.
- Keep security gates fail-closed. Test negative paths as well as successful paths.
- Pin external actions to full commit SHAs and deployed images to immutable digests.
